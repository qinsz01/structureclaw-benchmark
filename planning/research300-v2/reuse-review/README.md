## 哪些需要重组

**交互是最值得优先重组的部分。** 旧 INT 共 215 轮，其中大量是补一个字段、确认一个单位或改一个数后结束。保留必要澄清及直接执行的基础对照，再将有工程意义的局部修改、荷载归属、材料分组、查询和撤销组合起来。不能只把两轮改成六次重复改同一个值。

例如 INT-013/021/052/071 可以复用模型和字段更新方式，重组为“只改一组截面、保留另一组、移载、撤销截面但保留移载”；INT-055/060/065/078 可以转为多个工况之间的局部替换与组合保持；INT-079/080/081/082 的商业框架仍值得复用，补字段不再是唯一考点。

**多模态要按实际候选输入判断。** 冻结归档中的 100 个首轮候选包是 **77 个仅 PNG 附件、23 个仅 DXF 附件**，每包另有任务 JSON；没有把维护者 SVG 制图源一并提供给候选。不能从原始契约出现 SVG 就断言候选绕开图片。这里核查的是已验证归档的候选文件清单，不是再跑一次候选，也不证明每幅图的信息质量已经完成盲审。

MM-007/021/032/058/072 的“先缺图或冲突、再补图”可作为 INT 的视觉澄清素材；若进入新版单轮 MM，应给完整图纸，分别考图纸重建和交互。应保留 MM-039、061、074、090 等有效连接/边界/朝向难点，减少单纯换跨度和长小数表的重复。图片中的必要参数必须清楚；工程单位与有效位数调整后，参考必须跟随实际公开输入重新计算。

**评分和交付也要重新组织。** 轴力杆的 E/A/拓扑错误与非作用字段 J 的抄写不同；数值响应、输入复原和交付完整性应分开报告。新任务可采用正文摘要加完整结构化表/工件，不必要求把数百个量同时抄在正文和文件里。旧任务原来明确要求两处交齐，因此 STD-080/088 的历史失败仍保留，不能倒改为通过。

| 已有失败 | 本轮建议 |
| --- | --- |
| STD-080、STD-088 | 保留原生物理模型；整理新版本交付规范，历史得分不变 |
| INT-033 | 保留查询与控制量符号题核，不为让 Codex 通过而删除 |
| MM-039 | 保留轴力杆/梁的实质区别 |
| MM-041 | 保留空间杆系；J 抄写与轴向响应分别记，不称其为轴向算错 |
| MM-015、MM-070、MM-090 | 清晰组织参数表，并按物理作用区分复原和响应；不直接忽略 J，也不放宽全部容差 |

## 新版配额还要怎样落实

上一轮的 300 条是配额与任务意图目录，尚不是旧题到新题的完整迁移映射。不能把本次“优先题核 + 重组素材 = 240”直接当成 240 道新版成题。

按当前规划，90 个工程来源名额与 30 个模态/时程名额有 9 项重叠，所以 **至少 111 个名额必须新编任务与参考**。动力可以借用旧静力模型的几何/刚度，但新增质量、激励、响应与真值不能直接继承；工程题必须有实际来源与明确简化范围，不能只给旧题换工程名称。剩余 189 个是可考虑复用旧静力题的名额上限，还不是已找到 189 个合适匹配。

**150 个三维题的配额需要重新校准。** 旧题首个模型为二维 237、三维 63；当前 189 个“可复用”规划槽位中，二维 81、三维 108。即便把旧三维题全部使用，这部分仍至少需要 45 个新的三维物理输入，且结构类型/引擎不匹配可能再增加工作。不能把二维题改成三维后仍声称数值参考原样复用。

建议先落实真实工程资料与旧题迁移，再定最终二维/三维配比；工程改编名额应随实际项目分布安排，而不是按编号把普通梁题机械标成“工程目标”。整体 60/120/90/30 难度梯度可以保留，结构配额与来源位置应允许据此调整。300 个不同标题、244 个当前精确几何/支承分组，都不能代替新拓扑多样性验收；后者还需去除尺度、镜像和合理分段等影响。
