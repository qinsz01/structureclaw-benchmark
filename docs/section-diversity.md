# 截面参数多样性候选版：section-diversity-v1

原题库有 228/300 题在实际使用的截面中出现同一个 J；主要来自共用的编题附录。
这一版减少参数重复，同时保留原始工程情境和交互考点。它是独立候选版，当前默认题库和历史 Codex 282/300 成绩保持原有版本绑定。

## 设计边界

- **266 题调整，34 题固定。** 原始规格或对话明确指定的尺寸、HW 型钢及非对称截面对照题保持物理参数。固定题及逐题理由列在 [分配表](../planning/section-diversity-v1-r2.json) 的 `cases` 中。
- **一次变化对应完整截面。** 在题内采用共同的线性尺寸比例 s，面积及显式剪切面积乘 s²，Iy、Iz、J 乘 s⁴。矩形的 A/I/J 与 B/H 重新核对；广义数值截面的题定刚度比例继续成立。材料、几何、支承、局部轴、荷载、组合和观测位置保留。
- **多轮采用同一规则。** 新旧截面版本、撤销、截面切换和相对刚度修改都保留原关系。每个公开文件只转换其原本已有的数据，后续附件和冲突不会提前发布或被编题器自动解决。
- **按题型和引擎分别均衡。** 十个有界尺寸比例为 0.80、0.84、0.88、0.92、0.96、1.04、1.08、1.12、1.16、1.20。稳定哈希打散相邻题号，每个题型/引擎层内各档数量最多差 1。分配过程不读取候选答案、成绩或失败名单。PKPM 的矩形尺寸额外检查为整数毫米。
- **数值可读。** 公开截面参数采用 8 位有效数字，保留原单位；详细模型保留高精度。实际公开属性与模型的最大相对差为 4.761×10⁻⁸，低于原 10⁻⁶ 物理属性容差。额外使用实际公开属性重新计算响应，核对原有结果容差。

这些是理想化弹性截面的参数变化，并非新增可采购型钢目录。共同尺寸缩放保留原有长宽比、强弱轴及截面间关系；本版改善参数覆盖，未增加拓扑类型、材料类别或结构非线性能力覆盖。

## 覆盖变化

以“某题任一模型状态中实际分配给构件的截面”为统计口径；同题多个状态去重，忽略未使用的附录行。数值按公开的 8 位有效数字归并。

| 指标 | 原版 | 候选新版 |
| --- | ---: | ---: |
| 重复最多的 J 覆盖题数 | 228/300（76%） | 26/300（8.67%） |
| 实际使用的不同 J | 50 | 146 |
| 不同矩形尺寸组合 | 43 | 131 |
| 不同截面属性组集合 | 87 | 155 |
| 同一截面属性组集合最多复用题数 | 74 | 10 |
| STD 内重复最多的 J | 76/100 | 10/100 |
| INT 内重复最多的 J | 79/100 | 9/100 |
| MM 内重复最多的 J | 73/100 | 14/100 |
| OpenSees 内重复最多的 J | 197/267 | 20/267 |
| PKPM 内重复最多的 J | 15/16 | 3/16 |

固定尺寸题仍会出现重复数值，这是保留原始要求的结果。自动检查限制同一 J 的全库覆盖率不超过 15%、单题型不超过 20%、单引擎不超过 25%。这些阈值用于防止参数分布退化，不是工程数值容差，也不代表题库整体多样性已穷尽。

本地已生成 300 题、420 轮公开任务，全部通过现有导出器的来源绑定、逐轮释放、格式和图纸确定性核对。300 题的原始需求、数值请求和容差均保持一致；公开 JSON 中的非截面数字及结构图形实体也逐项核对。

300 题、364 个物理状态、8,187 个请求量通过独立矩阵法与真实 OpenSees 的交叉计算；全部状态同时通过使用实际公开属性的精度检查。另有原生解析轴拉/扭转测试验证面积和 J 的缩放规律。

**本地完整实测已完成，正式实验状态仍为候选。** 267 题 OpenSees、16 题 PKPM、17 题 YJK 均具有绑定当前题源的原生参考证据；完整参考审查通过 300/300，独立原始输入及响应物理审查覆盖 475 次运行。新版输入的外部独立重建盲审及正式 StructureClaw 试验尚未完成，`accepted=0`，不能把本地作者复核写成独立验收。

实际 Codex 300 题、420 轮统一按 r23 评分：**292/300 题、412/420 轮通过**，没有待处理的评分复核请求。8 道失败中，4 道截面参数误读、1 道桁架建模错误、1 道派生极值符号错误、2 道正文交付不完整。原始作答未改写，数值容差未放宽。原版 282/300 独立保留，不能与本版分数直接当作同题重测比较。

全量 r2 试跑中，30 道公开题面与应保留的约束不一致，修正后整题重新调用 Codex：r6 有 29 题，r7 有 1 题。最终保留 270 道题源和公开文件均未改变的 r2 作答，加上 30 道新会话；选择由题源版本决定，不按分数择优。原始调用、被排除记录、旧评分与参考值都保留。

STD-089、STD-091 的商业引擎参考曾使用公开参数之外的小数位，独立原生复算已改为题面实际公布的 8 位有效数字，避免候选输入正确却被高精度隐藏输入误判。修改绑定输入精度，不改变原评分容差。商业参考与保存的矩阵/OpenSees 跨引擎对照仍有 9 个量、18 条比较超出严格容差，集中在这两题；把矩阵输入同样限定为公开小数后，447 个量中仍有 8 个超限。严格失败如实保留，不能表述为跨引擎全部一致，也不把经验精度诊断当作已证明的误差上界。

完整实测报告与离线复现提供逐题结果、失败说明、全部原始调用和新版题库快照。早期多样性设计验证保留其当时的范围和状态。

## 本地复现

使用已安装 `requirements-research300.txt` 依赖的 Python 环境，并执行 `npm ci` 安装图纸渲染依赖。以下输出路径必须是新目录；命令不会覆盖已有产物。

```sh
npm run test:section-diversity
npm run audit:section-diversity -- --output /tmp/section-diversity-audit.json
npm run build:section-diversity -- --output /tmp/research300-diversity-v1

node scripts/build-research300-manifest.cjs \
  --root /tmp/research300-diversity-v1 \
  --output /tmp/research300-diversity-v1/corpora/research-300/manifest.json
python3 scripts/research300/public_input_clean.py --root /tmp/research300-diversity-v1
node scripts/export-research300-inputs.cjs \
  --root /tmp/research300-diversity-v1 --output /tmp/research300-diversity-inputs

python3 scripts/research300/verify_section_diversity.py \
  --edition-root /tmp/research300-diversity-v1 \
  --output /tmp/research300-diversity-diagnostics --workers 3
```

供模型作答时只使用最后导出的 `research300-diversity-inputs`，按轮次释放附件。
构建根目录和 diagnostics 含维护者模型及参考计算，不应作为模型工作目录。实验配置须记录新题包的来源/输入绑定及本版计划哈希。

新增题目或改动原题后，先重新审核固定尺寸清单、可调整参数和分配规则，再生成新的计划版本及完整数值/输入检查。已用于候选实测的计划应保留归档，不能通过修改种子或筛选失败题改善成绩。
