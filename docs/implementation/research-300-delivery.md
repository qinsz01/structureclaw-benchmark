经用户授权，数值模型与求解脚本在 246 的隔离目录调用了 PKPM/YJK。题面、答案和评分规则保留在 benchmark 服务器，未向远端模型发送；未修改 StructureClaw 或数据工厂，未在 83 节点运行求解。本轮自有进程与任务已清理，原有 launcher 保留。

33 道商业题公开采用 `commercial-linear-static-v2`：一阶 Timoshenko 梁柱、有效剪切面积 `Asy=Asz=5*A/6`。商业评分参考现为经过独立审查的原生结果；原矩阵参考逐字节另存为诊断。候选结果、命名审查、原始输入与结果、实际版本、状态和工况均经摘要绑定；修改评分值、原始证据或收据会使原生验证失效。商业证据与离线复放保留实际轴和符号、缺失 SDK 值的边界推导、原生精度及适用范围。

`research300-evaluator-v3` 的默认限值为原绝对容差加原相对容差乘原生参考绝对值。此前 v2 将 `gamma_(2*n-1) * sum(abs(term))` 加入默认限值；这一公式虽可独立复算，却没有证明 PKPM 实际运算的误差界，不能用于宣布严格差异已修复。120 项 `native-f32-recovery-scale-v1` 证书仍按原字节保留，其结果明确标为 `diagnosticOnly`。比较器、总评分和 CLI 均按严格结果判定；有效但不一致的证据输出 `evidenceValid=true, strictPass=false, engineeringPass=true`，商业诊断 CLI 返回 1。原生自身比较仍通过，失效证据、错误单位和派生传播仍被拒绝。详见本轮调查与修复和[双轨诊断结果](../../corpora/research-300/evidence/commercial-native-diagnostic-comparison.json)。
